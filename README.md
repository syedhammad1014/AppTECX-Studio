# AI & Machine Learning Internship Portfolio (8 Weeks)

Learning projects covering the topics of my AI/ML internship at App Tecx Studio (June–August 2026):
Python for AI/ML, data cleaning, EDA, visualization, supervised & unsupervised algorithms,
feature engineering, model evaluation, and an end-to-end predictive application.

## Datasets
| Dataset | Source | Used in |
|---|---|---|
| Iris, Diabetes, Wine | scikit-learn built-in | Weeks 1, 4, 6 |
| Customer Churn (messy, 1,540 rows) | Synthetic, generated by `data/generate_data.py` (seeded) | Weeks 2-8 |

## Main findings
- Month-to-month contracts churn at ~39% vs ~11% for two-year contracts; short tenure and many support calls raise churn risk (Week 3).
- On the churn data, Logistic Regression and Naive Bayes had the best F1 (~0.60); Random Forest did not beat them, which is plausible because the data's churn signal is roughly linear (Week 7).
- Churn is imbalanced (~30%), so recall on churners is low (~0.42 for the final model). Next steps: class weights, threshold tuning, SMOTE.
- Wine dataset: SVM and Naive Bayes reached 97.8% accuracy; KMeans with k=3 had the best silhouette score (0.285).

## Honest notes
The churn dataset is synthetic and built for practice, so results do not describe real customers.
